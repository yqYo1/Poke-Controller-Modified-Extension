## 1. 概要

Poke-Controller Modified Extension は、Nintendo Switch をシリアル通信（UART）経由で制御するためのクロスプラットフォームデスクトップアプリケーションです。Pico/RP2040 マイクロコントローラと連携し、PC から Switch に対してボタン入力、スティック操作、タッチスクリーン制御、カメラキャプチャなどを実行できます。

`refactor/rust-core` ブランチでは、従来の Python/PyQt5 アーキテクチャから **Tauri（Rust）** バックエンドと **Svelte 4** フロントエンドへの全面刷新を行っています。

### 1.1 技術スタック

| レイヤー     | 技術                          |
|------------|-------------------------------|
| バックエンド | Rust + Tauri                 |
| フロントエンド | Svelte 4 + Vite              |
| シリアル通信  | `serialport` crate           |
| カメラ      | OpenCV（Tauri コマンド経由）    |
| WebSocket  | `tokio-tungstenite`          |
| IPC        | Tauri コマンド + イベント       |

### 1.2 動作環境

- **OS**: Windows 10/11, macOS, Linux
- **マイコン**: Raspberry Pi Pico / RP2040 ボード（Poke-Controller ファームウェア書き込み済み）
- **接続**: USB シリアル（UART）— デフォルト 115200 baud
- **カメラ**: USB カメラまたは内蔵カメラ（OpenCV が認識可能なもの）

## 2. インストール

### 2.1 Nix を使用する場合（推奨）

プロジェクトは Nix flake に対応しています。Nix がインストールされている環境では、以下のコマンドで開発シェルに入れます。

```bash
# 開発環境に入る（依存関係を自動解決）
nix develop

# アプリケーションを直接実行
nix run
```

### 2.2 手動ビルド

Rust と Node.js がインストールされている環境では、以下の手順でビルドできます。

```bash
# リポジトリをクローン
git clone <repository-url>
cd Poke-Controller-Modified-Extension

# フロントエンドの依存関係をインストール
cd web
npm install

# Tauri アプリケーションをビルドして起動
npx tauri dev
```

### 2.3 初回セットアップ

1. Pico を PC の USB ポートに接続します
2. アプリケーションを起動します
3. Serial タブで正しいポートと baud rate（デフォルト: 115200）を選択し、接続します
4. 必要に応じて Camera タブでカメラソースを選択します

## 3. Web UI 概要

アプリケーションのメインインターフェースは、上部のナビゲーションバー（NavBar）と左側のサイドバー、中央のメインコンテンツエリア、右側の出力パネルで構成されます。

### 3.1 ナビゲーションバー（6 タブ）

上部の NavBar には以下の 6 つのタブがあります。

| # | タブ          | 説明                                    |
|---|-------------|----------------------------------------|
| 1 | **Camera**  | カメラプレビュー、設定、マウス操作           |
| 2 | **Serial**  | シリアルポート接続、モニタリング              |
| 3 | **Manual Control** | 手動コントローラー操作              |
| 4 | **Commands** | Python/MCU/ショートカット コマンド実行      |
| 5 | **Notification** | 通知設定（Windows / Discord）        |
| 6 | **Others**  | ウィジェットモード、出力設定、表示設定        |

### 3.2 サイドバー

左側のサイドバーには、シリアルポートの選択・接続に関するコントロールが配置されています。

- ポート選択ドロップダウン
- ボーレート（Baud rate）設定
- 接続／切断ボタン
- 接続状態インジケータ

### 3.3 出力パネル

右側のパネルには、上部と下部の 2 つのログパネルがあります。シリアルデータのルーティングに応じて各パネルにログが表示されます（詳細は[第10章](#10-出力パネル)参照）。

## 4. Camera タブ

Camera タブでは、Switch の画面をキャプチャするためのカメラプレビューと各種操作が行えます。

### 4.1 カメラプレビュー

- カメラのライブフィードをリアルタイムで表示します
- 解像度は CameraSettings からユーザーが設定可能です
- フレームレートは 1〜30 FPS の範囲で設定可能（範囲外の値は自動的にクランプされます）

### 4.2 カメラ設定（CameraSettings）

CameraSettings コンポーネントでは以下の設定が行えます。

| 設定項目     | 説明                              |
|------------|-----------------------------------|
| ソース      | 使用するカメラデバイスの選択               |
| 解像度      | キャプチャ解像度の設定                    |
| FPS        | フレームレート（1〜30）                  |
| フリップ     | 映像の反転                            |
| 回転       | 映像の回転角度                         |

### 4.3 表示モード

プレビュー画面上のオーバーレイ表示を切り替えられます。

- **テンプレートマッチ結果** — 画像認識のマッチ位置を表示
- **矩形（Rectangle）** — 検出領域の矩形を表示
- **テキストアノテーション** — 画面上のテキスト注釈を表示

### 4.4 マウス操作

Camera タブでは、マウスを使用した高度な操作が可能です。操作モードはツールバーのボタンで切り替えます。

| 操作                    | 内容                                    |
|------------------------|-----------------------------------------|
| **ドラッグ（通常）**      | カメラビューの**スティック操作**として機能    |
| **Ctrl + クリック**      | カーソル位置の色を**カラーピッカー**で取得   |
| **Ctrl + Shift + ドラッグ** | 選択範囲の**スクリーンショット**を保存    |
| **Ctrl + Alt + ドラッグ** | 選択範囲に**名前を付けて保存**            |

### 4.5 マウス操作モード

ツールバーで以下のモードを切り替えられます。

| モード                | 説明                                    |
|---------------------|----------------------------------------|
| **パン（Pan）**       | クリック＆ドラッグでカメラビューを移動        |
| **ズーム（Zoom）**    | スクロールホイールで拡大／縮小              |
| **テンプレート選択**   | 矩形をドラッグしてテンプレート領域を定義       |
| **クロップ（Crop）**  | キャプチャ範囲を矩形で選択                  |

### 4.6 スクリーンショット形式

カメラツールバーから、スクリーンショットの保存形式を選択できます。

- **PNG** — 可逆圧縮、高品質
- **JPEG** — 非可逆圧縮、ファイルサイズ小

## 5. Serial タブ

Serial タブでは、Pico マイコンとのシリアル通信を管理します。

### 5.1 ポート接続

1. **ポート選択**: 利用可能なシリアルポートの一覧から、Pico が接続されているポートを選択します
2. **ボーレート設定**: 通信速度を設定します（デフォルト: 115200）
3. **接続**: 「接続」ボタンをクリックしてシリアル通信を開始します
4. **切断**: 通信終了時は「切断」ボタンをクリックします

### 5.2 通信パラメータ

| パラメータ      | デフォルト値  | 備考                |
|-------------|----------|--------------------|
| Baud rate   | 115200   | 標準設定               |
| Data bits   | 8        |                     |
| Parity      | None     |                     |
| Stop bits   | 1        |                     |
| 改行コード     | `\r\n`   | ライン終端              |

### 5.3 モニター（RX/TX）

シリアル通信のモニタリング機能を提供します。

- **TX（送信）**: アプリケーションから Pico に送信されたコマンドを表示
- **RX（受信）**: Pico からアプリケーションに送信されたデータを表示

モニター画面では、通信データをリアルタイムで確認でき、シリアルデータは WebSocket 経由で出力パネルにもルーティングされます。

### 5.4 ワイヤーフォーマット

シリアル通信のワイヤーフォーマットは以下のとおりです。

```
0xXXXX HH XX XX XX XX\r\n
```

| フィールド      | サイズ     | 説明                    |
|--------------|----------|-----------------------|
| `0xXXXX`     | 16-bit   | ボタンビットマスク           |
| `HH`         | 8-bit    | Hat（十字キー）位置         |
| `XX XX`      | 8-bit x 2 | 左スティック（X, Y）       |
| `XX XX`      | 8-bit x 2 | 右スティック（X, Y）       |

## 6. Manual Control タブ

Manual Control タブでは、Switch を手動で操作するためのコントロールを提供します。3 つの操作モードがあります。

### 6.1 Software Control（ソフトウェア制御）

キーボードとマウスを使用した操作モードです。

- **キーボード操作**: 各ボタン（A, B, X, Y, L, R, ZL, ZR など）にキーボードキーを割り当て可能
- **マウス操作**: マウスクリックで仮想ゲームパッドのボタンを押下
- **十字キー（D-Pad/Hat）**: 方向入力
- **アナログスティック**: 左スティック・右スティックの傾きをマウスまたはスライダーで操作
- **タッチスクリーン**: 座標指定によるタッチ操作

### 6.2 Hardware Control（ハードウェア制御）

実際のゲームパッド（コントローラー）を PC に接続して使用するモードです。

- 対応コントローラー: USB 接続のゲームパッド
- ボタンマッピング: コントローラーの各ボタンが Switch の対応ボタンにマッピングされます
- アナログスティック: コントローラーのスティック入力をそのまま Switch に転送

### 6.3 Controller Simulator（コントローラーシミュレーター）

画面上の仮想コントローラーをマウスで操作するモードです。

- 画面上に Nintendo Switch のコントローラーイメージが表示されます
- 各ボタンをマウスクリックで押下できます
- スティックはドラッグで操作可能
- 実際のコントローラーがなくても Switch 操作が行えます

### 6.4 レコード機能

Manual Control タブには**レコードチェックボックス**があります。

- チェックボックスが ON の状態で操作を行うと、シリアルコマンドが記録されます
- 記録されたコマンドは後で再生・編集が可能です
- チェックボックス（トグルボタンではなく）で ON/OFF を制御します

## 7. Commands タブ

Commands タブでは、自動化スクリプト（コマンド）の管理と実行を行います。

### 7.1 サブタブ

Commands タブは 3 つのサブタブで構成されています。

| サブタブ       | 説明                                    |
|-------------|---------------------------------------|
| **Python**  | Python で書かれた自動化スクリプトの一覧と実行      |
| **MCU**     | マイコン側で実行するファームウェアコマンド          |
| **Shortcut** | よく使う操作を割り当てたショートカットボタン        |

### 7.2 Python コマンド

- Python コマンドの一覧が表示されます
- コマンド名またはタグで検索・フィルタリングが可能です
- コマンドを選択して「実行」ボタンをクリックすると、Tauri バックエンドでスクリプトが実行されます
- 各コマンドにはユーザーが割り当てた**タグ**が表示され、タグによるフィルタリングも可能です

### 7.3 MCU コマンド

- マイコン（Pico）側に書き込まれたコマンドを実行します
- ファームウェア側の処理を呼び出すため、PC のリソースを消費しません
- MCU コマンド固有のタグで出力ログのフィルタリングも可能

### 7.4 Shortcut（ショートカットボタン）

Shortcut サブタブには、**10 個のショートカットボタン**が表示されます。

- 各ボタンによく使うコマンドや操作を割り当てられます
- ワンクリックで割り当てた操作を実行
- ボタンの割り当ては設定画面から変更可能

### 7.5 キーボードショートカット

Commands タブでは以下のキーボードショートカットが使用できます。

| キー              | 機能                  |
|-----------------|---------------------|
| **F5**          | コマンド一覧を**リロード** |
| **F6**          | 選択中のコマンドを**開始**  |
| **Shift + F6**  | 実行中のコマンドを**一時停止** |
| **Escape**      | 実行中のコマンドを**停止**   |

> **注意**: F5 は「開始」ではなく「リロード」です（旧バージョンからの変更点）。重複したショートカット割り当てはありません。

## 8. Notification タブ

Notification タブでは、コマンド実行の開始・終了時に通知を送信する設定を行います。

### 8.1 Windows 通知

- コマンド開始時に Windows のシステム通知を表示
- コマンド終了時に Windows のシステム通知を表示
- 設定はコマンドクラスの属性 `isWinNotStart` / `isWinNotEnd` で制御

### 8.2 Discord Webhook

Discord の Webhook を使用した通知設定です。

| エンドポイント                          | 説明                     |
|-------------------------------------|------------------------|
| `POST /api/notification/discord-text` | テキスト通知を送信           |
| `POST /api/notification/discord-image` | テキスト + カメラ画像を送信  |

**設定項目**:

- Webhook URL（環境変数 `DISCORD_WEBHOOK` または設定ファイル）
- 通知タイミング（開始時／終了時）
- 送信内容のカスタマイズ

Discord 通知の設定は Python スクリプト内でも以下のメソッドで制御できます。

```python
# テキスト通知
self.discord_text(content="メッセージ", index=0)

# 画像付き通知
self.discord_image(content="メッセージ", index=0, crop_fmt='', crop=None)
```

### 8.3 Python コマンドでの通知設定

コマンドクラスの属性で通知動作を制御できます。

| 属性               | 型      | デフォルト | 説明                         |
|------------------|---------|--------|----------------------------|
| `isWinNotStart`  | `bool`  | `False` | 開始時に Windows 通知を表示       |
| `isWinNotEnd`    | `bool`  | `False` | 終了時に Windows 通知を表示       |
| `isDiscordNotStart` | `bool` | `False` | 開始時に Discord 通知を送信     |
| `isDiscordNotEnd`   | `bool` | `False` | 終了時に Discord 通知を送信     |

## 9. Others タブ

Others タブでは、アプリケーションの各種設定を行います。

### 9.1 Widget Mode（ウィジェットモード）

ダイアログで使用するウィジェットのモードを選択します。以下の **7 モード** が利用可能です。

| # | モード    | 説明                                    |
|---|---------|---------------------------------------|
| 1 | **Entry** | テキスト入力フィールド                      |
| 2 | **Check** | チェックボックス                          |
| 3 | **Combo** | コンボボックス（ドロップダウン選択）            |
| 4 | **Radio** | ラジオボタン                              |
| 5 | **Spin** | スピンボックス（数値選択）                   |
| 6 | **Scale** | スケール（スライダー）                      |
| 7 | **Next** | 次のカラムへ移動（レイアウト制御）             |

これらのモードは、Python コマンド内の `dialogue6widget()` メソッドで使用されます。

### 9.2 Output Size（出力サイズ）

出力パネル（ログパネル）の表示サイズを設定します。

- 上部パネルと下部パネルの比率を調整可能
- パネルの境界線をドラッグしてサイズを変更することも可能

### 9.3 Stdout Destination（標準出力の出力先）

Python の `print()` 関数の出力先となるログパネルを選択します。

| 設定値 | 出力先      |
|-------|-----------|
| `"1"` | 上部パネル   |
| `"2"` | 下部パネル   |

Python コマンドのクラス属性 `stdout_destination` でも設定可能です。

### 9.4 Controller Position（コントローラー位置）

Manual Control タブの仮想コントローラーの表示位置を設定します。

- 画面上でのコントローラー表示位置をカスタマイズ
- プリセット位置から選択、または自由に配置可能

### 9.5 Dialogue Position（ダイアログ位置）

設定ダイアログやコマンドパラメータ入力ダイアログの表示位置を設定します。

| 設定値 | 説明              |
|-------|-----------------|
| 1     | 画面上部に表示       |
| 2     | 画面中央に表示（デフォルト）|
| 3     | 画面下部に表示       |

Python コマンドのクラス属性 `pos_dialogue_buttons` でも設定可能です。

```python
class MyCommand(ImageProcPythonCommand):
    pos_dialogue_buttons = 2  # 中央表示
```

## 10. 出力パネル

出力パネル（Output）は、アプリケーションの右側に表示される 2 つのログパネルです。

### 10.1 パネル構成

- **上部パネル**: 主に Python コマンドからの出力（`print_t1()`）、シリアル RX データなどを表示
- **下部パネル**: 補助的なログ出力（`print_t2()`）などを表示

### 10.2 出力データの種類

出力パネルには以下のデータが表示されます。

| データ種別          | 説明                              |
|-----------------|---------------------------------|
| シリアル RX データ   | Pico からの受信データ（WebSocket 経由） |
| WebSocket ログ   | WebSocket 通信のログ                |
| Python コマンド出力 | 各パネル向けの print 出力           |
| MCU コマンドログ    | タグ付きの MCU コマンドログ           |

### 10.3 ログレベルフィルター

出力パネルでは、表示するログの重要度をフィルタリングできます。

| レベル     | 説明                |
|----------|-------------------|
| **DEBUG** | デバッグ情報（最も詳細）    |
| **INFO**  | 通常の情報            |
| **WARN**  | 警告                |
| **ERROR** | エラー（最も重要）       |

フィルターを変更すると、上部パネルと下部パネルの両方に適用されます。

### 10.4 クリップボードへのコピー

出力パネルの内容をクリップボードにコピーできます。

1. コピーしたいログエントリを選択
2. パネル右上の「コピー」ボタンをクリック
3. 選択した内容がクリップボードにコピーされます

内部では `navigator.clipboard.writeText()` を使用しています。

### 10.5 タグ表示とフィルター

- 各ログエントリには**タグ**が表示されます
- MCU コマンド固有のタグでフィルタリングが可能です
- タグフィルターは一般のタグフィルターとは独立して動作します

### 10.6 出力のクリア

出力パネルの内容をクリアするには、パネル右上の「クリア」ボタンをクリックします。上部パネルと下部パネルは独立してクリア可能です。

## 11. トラブルシューティング

### 11.1 シリアル接続の問題

**症状: ポートが見つからない / 接続できない**

| 原因                           | 解決策                                      |
|------------------------------|-------------------------------------------|
| Pico が認識されていない             | USB ケーブルを抜き差しする。デバイスマネージャーで認識を確認 |
| ポートが他のアプリケーションで使用中       | 他のアプリケーション（旧バージョンなど）を終了する            |
| ドライバーが不足している              | Pico の CDC ACM ドライバーをインストールする           |
| 権限が不足している（Linux）          | ユーザーを `dialout` グループに追加する                 |

```bash
# Linux での権限設定
sudo usermod -a -G dialout $USER
# 再ログイン後、設定が反映されます
```

**症状: 通信が不安定 / データが化ける**

| 原因                            | 解決策                                     |
|-------------------------------|------------------------------------------|
| ボーレートが一致していない               | 両端で同じボーレート（115200）に設定する               |
| シリアルケーブルの品質                  | シールドされた USB ケーブルを使用する                  |
| 電源が不安定                       | Pico に安定した電源を供給する（USB ハブ経由を避ける）      |

### 11.2 カメラの問題

**症状: カメラが認識されない**

| 原因                       | 解決策                                 |
|--------------------------|--------------------------------------|
| カメラが他のアプリケーションで使用中    | 他のアプリケーションを終了する                  |
| ドライバーが不足している           | カメラのドライバーをインストールする               |
| 権限が不足している（Linux/macOS） | カメラへのアクセス権限を付与する                  |
| OpenCV がカメラを認識できない     | CameraSettings で別のソース番号を試す           |

**症状: フレームレートが低い / 画面がカクつく**

| 原因                  | 解決策                        |
|---------------------|-----------------------------|
| 解像度が高すぎる           | 解像度を下げる（例: 640×480）       |
| FPS 設定が低い          | CameraSettings で FPS を上げる  |
| CPU リソースが不足している    | 他のアプリケーションを終了する            |

### 11.3 コマンド実行の問題

**症状: コマンドが実行されない**

| 原因                       | 解決策                          |
|--------------------------|-------------------------------|
| シリアルポートが接続されていない        | Serial タブで接続を確認する           |
| コマンドのシンタックスエラー          | コマンドのコードを確認する               |
| コマンドが実行中でない             | F6 キーでコマンドを開始する             |
| 別のコマンドが既に実行中           | Escape キーで現在のコマンドを停止してから再試行 |

**症状: コマンド一覧が空 / 古い**

| 原因                  | 解決策                     |
|---------------------|--------------------------|
| コマンド一覧が最新でない        | F5 キーでリロードする            |
| スクリプトのパスが間違っている      | コマンドディレクトリの設定を確認する     |

### 11.4 通知の問題

**症状: Discord 通知が送信されない**

| 原因                          | 解決策                              |
|-----------------------------|-----------------------------------|
| Webhook URL が設定されていない      | Discord Webhook URL を設定する         |
| 環境変数 `DISCORD_WEBHOOK` が未設定 | `.env` ファイルまたは環境変数を設定する         |
| ファイアウォールがブロックしている         | ファイアウォールの設定を確認する                |

### 11.5 アプリケーション全般

**症状: アプリケーションが起動しない**

| 原因                     | 解決策                      |
|------------------------|---------------------------|
| 依存関係が不足している           | `nix develop` または `npm install` を再実行 |
| Tauri のシステム依存関係が不足    | 必要なシステムライブラリをインストールする     |
| ポート番号が競合している          | 他のアプリケーションを終了する           |

**症状: 出力パネルにログが表示されない**

| 原因                        | 解決策                               |
|---------------------------|------------------------------------|
| WebSocket 接続が確立されていない    | アプリケーションを再起動する                   |
| ログレベルフィルターが強すぎる         | フィルターを DEBUG または INFO に設定する      |
| 出力先のパネルが正しく設定されていない    | Stdout Destination の設定を確認する      |

### 11.6 ログの確認方法

問題が解決しない場合は、アプリケーションのログを確認してください。

- **アプリケーションログ**: Tauri のコンソール出力
- **WebSocket ログ**: 出力パネルに表示される WebSocket 通信ログ
- **シリアルログ**: Serial タブの RX/TX モニター

### 11.7 サポート

問題が解決しない場合は、以下の情報を添えてサポートにお問い合わせください。

- アプリケーションのバージョン
- OS の種類とバージョン
- 使用しているマイコンボード
- エラーメッセージのスクリーンショット
- 再現手順
